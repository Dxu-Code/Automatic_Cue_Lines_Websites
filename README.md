Cue

Cue helps you learn lines from a script. Click a line to learn it, and the two lines before it show up as a hint.

Live app: https://yourusername.github.io/cue-lines/ How to use it: https://yourusername.github.io/cue-lines/how-to-use.html

What it does
Upload a .txt script, or type your lines by hand

Click any line to mark it as one you need to learn

The two lines before it pop up as a hint, so you always know your cue

Quick-select buttons let you grab all of one character's lines at once

Put the exact words to memorize inside ( ) or [ ] — everything else gets highlighted, so you know it's just extra text

Pick your own highlight color

A "Rehearse" mode hides your line and shows only the hint, so you can test yourself

Everything is saved in your browser automatically

How to use it:
- Open the app.
- Add your script (upload a file, or type it in).
- Click the lines you want to learn.
- Go to the Rehearse tab to practice.

For the full step-by-step guide, see how-to-use.html.

Running it yourself

No install needed. It's a single HTML file.

Download index.html.
Open it in any browser.

That's it.
